# sc-deken Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build sc-deken: a Go helper (`scdeken`) plus a SuperCollider quark (`Deken`) that search, install, build, update, remove and retract SuperCollider plugins and quarks, backed by a GitHub recipes repository whose CI builds, signs and indexes packages.

**Architecture:** One Go binary does all the real work: recipes, signed index, search, download and verify, local CMake builds, doctor, indexer, tag bot. The same binary runs on user machines and in CI. A thin sclang quark bootstraps the helper, talks to it through request/result JSON files and OSC progress messages, and draws the layout-B GUI. A second repo (`sc-deken-recipes`) holds TOML recipes and advisories. Its GitHub Actions build, sign and publish `index.json` to Pages and binaries to Releases.

**Tech Stack:** Go ≥ 1.23 (stdlib + `github.com/BurntSushi/toml` + `aead.dev/minisign`), sclang (SuperCollider ≥ 3.13, Qt GUI), GitHub Actions, CMake, vcpkg (CI static deps).

**Spec:** `docs/superpowers/specs/2026-10-24-sc-deken-design.md` (approved). Read it before any task. Section numbers below (§n) refer to it.

  type Package struct {
  	Name, Summary, Repo, License string                 // json: name, summary, repo, license
  	Authors       []string                              `json:"authors,omitempty"`
  	Kind          recipe.Kind                           `json:"kind"`
  	Trust         Trust                                 `json:"trust"`
  	Stars         int                                   `json:"stars"`
  	Pushed        time.Time                             `json:"pushed"`

  	Build         *recipe.Build                         `json:"build,omitempty"`
  	Requires      map[string]recipe.Requirement         `json:"requires,omitempty"`
  	Versions      []Release                             `json:"versions"` // newest first
  }
  type Release struct {
  	Version  string  `json:"version"`
  	Commit   string  `json:"commit"`
  	Unstable bool    `json:"unstable,omitempty"`
  	Builds   []Build `json:"builds,omitempty"`
  }
  type Build struct {
  	Platform string `json:"platform"`

  	SHA256   string `json:"sha256"`

  }
  const SchemaVersion = 1
  func Decode(data []byte) (*Index, error)                   // error if Schema != 1: "index format 2 is newer than this sc-deken; please update sc-deken"
  func (ix *Index) Encode() ([]byte, error)                  // indented JSON, packages sorted by lowercase name
  func (ix *Index) Find(name string) (*Package, bool)        // case-insensitive name
  func (ix *Index) FindRepo(repo string) (*Package, bool)    // advisory.NormalizeRepo equality
  func (ix *Index) Release(p *Package, v string) (*Release, bool) // v=="" → Latest
  func (ix *Index) Latest(p *Package) (*Release, bool)       // newest stable release not retracted as malware; else newest unstable

  func (r *Release) BuildFor(k platform.Key) (*Build, bool)  // via Key.Accepts

  type SearchOptions struct{ IncludeUnreviewed bool; Kind recipe.Kind }

  	Latest    string `json:"latest"`
  	Retracted bool   `json:"retracted"`
  	Match     *Match `json:"match,omitempty"`    // nil for empty query
  }
  func Search(ix *Index, query string, opts SearchOptions) []Result

A package's match field is the strongest one among its terms, in the order name > summary > ugen > class. Sort by match field strength, then trust (reviewed > community > unreviewed), then stars descending, then name. An empty query returns everything, sorted by trust then name. Unreviewed packages are excluded unless `IncludeUnreviewed`. `Kind` filters exactly when non-empty.

  Behavior:
  - Every entry in `p.Confirm` must be satisfied by `Choices` (`duplicates` needs a non-empty `OnDuplicate`), else `*ConfirmationError`.
  - `OnDuplicate == "keep"` → record a `state.Entry{Route: External, Path: dup path}` and return `Kept`.

  - Any failure removes staging and leaves state untouched.
  - Success → `State.Packages[lower(name)] = Entry{…, Route prebuilt|local-build, Platform, Path, InstalledAt}`, then `State.Save`.
